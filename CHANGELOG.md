# Changelog

## 0.1.0

Initial public release.

- Hidden terminal credential entry and macOS Keychain storage.
- Hidden Chrome sign-in and automatic session recovery for recognized authentication failures.
- Direct HTTPS pharmacy reads: orders, order details, prescription availability, and communication preferences.
- Human-readable output and versioned JSON for agents.
- Local order-change history and polling.
- Read-only refill and cancellation previews; submission is not implemented.
- Modular boundaries for future appointments, messages, and records.
- Synthetic tests, type checks, formatting checks, and CI.

Credential storage is currently supported on macOS. MFA or browser challenges may still require human interaction. KP regional contracts may differ.
